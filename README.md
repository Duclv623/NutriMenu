# NutriGuide — frontend

Giao diện React và TypeScript nằm trong `frontend/`. Cài thư viện bằng `npm ci` trong thư mục đó rồi chạy `npm run dev`. Mở `http://127.0.0.1:5173/` để dùng bản demo.

Để kết nối RAG thật, chạy dịch vụ từ nhánh `chatbot-service` tại cổng 8000, rồi cấu hình frontend theo [hướng dẫn](frontend/README.md).
