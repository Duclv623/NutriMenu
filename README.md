# NutriGuide — dịch vụ chatbot

Mã FastAPI, cấu hình RAG và giao diện demo nằm trong `chatbot/`. Phiên bản này dùng ChromaDB cho tìm kiếm vector, kết hợp BM25 để tìm theo từ khóa.

Xem [hướng dẫn cài đặt, chuẩn bị dữ liệu và chạy chatbot](chatbot/README.md). Sau khi hoàn tất cấu hình, có thể chạy `./run-chatbot.ps1` từ thư mục gốc và mở `http://127.0.0.1:8000/`.
